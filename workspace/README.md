## How to use the `.sql` files

Open in **DB Browser for SQLite** → Execute SQL tab, or any editor. Each question is a
comment with the expected answer next to it. Write your query underneath, run it, compare.

**The expected answer is not the model solution.** It is a row count or a total so you
know whether to move on. The model SQL is in `reference/answers/` and it says *open me
second* for a reason — reading a solution before attempting produces recognition, not
recall, which is the exact failure this system exists to prevent.

## Nothing here is graded

Wrong turns are the useful part. Leave your broken attempts in the file above the working
one — the end-of-day digest reads these, and a query that failed tells the review queue
more than one that worked.
